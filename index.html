01

챗봇과 AI Agent

둘 다 같은 AI 모델을 씁니다. 다른 점은 손이 있느냐입니다.

01 · 무엇이 다른가

챗봇은 파일을 받고,
Agent는 폴더로 들어온다.

💬

챗봇

  • 파일을 하나씩 올려야 함
  • 결과를 복사해서 내가 붙여 넣음
  • "이렇게 해 보세요"로 끝남
VS
🤖

AI Agent

  • 내 폴더 안의 파일을 스스로 찾아 읽음
  • 엑셀·한글·브라우저를 직접 조작함
  • 끝난 뒤 결과를 스스로 확인함

01 · 작동 원리

읽고, 계획하고, 하고, 확인한다.

사람에게 일을 맡길 때와 같습니다. Agent는 일이 끝날 때까지 이 순서를 여러 번 돕니다.

① 읽기메모·파일 살펴보기
→
② 계획할 일 목록 세우기
→
③ 실행파일 수정·프로그램 조작
→
④ 확인결과 검산
↺

모델 고르기

어려운 일은 가장 똑똑한 모델, 단순 반복은 빠르고 가벼운 모델. 앱 아래쪽에서 바꿀 수 있습니다.

이름 정리

Claude Code(Anthropic) · Codex(OpenAI). 둘 다 "내 컴퓨터에서 일하는 AI Agent"입니다.

01 · 안전

손이 있으니, 규칙도 필요하다.

🔒

허락받고 움직인다

파일을 고치거나 명령을 실행하기 전에 승인 창이 뜹니다. 읽어 보고 누르세요.

🗂

원본은 따로

중요한 파일은 복사본으로 실습하세요. 작업 폴더 밖은 건드리지 않게 합니다.

🙈

개인정보는 빼고

학생 이름·연락처·성적은 넣지 않습니다. 넣은 내용은 AI 회사 서버로 전송됩니다.

02

로컬 작업

내 컴퓨터에 있는 파일을 AI가 직접 다룹니다.

02 · 몸풀기 · 폴더 0

깜빡한 숙제, 대신 해 줘.

그리기 동호회에서 이번 주 인물화를 깜빡했습니다. 참고할 그림을 찾아 폴더에 저장해 달라고 맡겨 봅니다.

실습 프롬프트
'0 로컬 작업- 그림 그리기' 폴더의 '그림그리기 설명.md'를 읽고, 거기 적힌 대로 해 줘.
  • 메모를 스스로 읽고 할 일을 파악했나요?
  • 폴더 안에 jpg 파일이 새로 생겼나요?

02 · 친목회 회계 · 폴더 1

결산했는데, 빠뜨린 게 있다.

상황

  • 3~4월 거래 4건은 엑셀에 정리해 둠
  • 10/6 회비 50만 원 입금 → 안 적음
  • 10/15 떡값 10만 원 지출 → 안 적음
  • 회비 입금자명은 '충북보은초'

성공 기준

  • 두 거래가 날짜순으로 들어갔다
  • 맨 위 수입·지출·잔액이 다시 계산됐다
  • 잔액이 이전보다 40만 원 늘었다
  • 기존 서식이 깨지지 않았다
실습 프롬프트
'1 로컬 작업 - 친목회 회계' 폴더의 '친목회 상황 메모.md'를 읽고, 빠진 거래를 '보은초 친목회 회계.xlsx'에 넣어 줘. 맨 위 결산(수입·지출·잔액)도 다시 맞추고, 끝나면 무엇을 바꿨는지 알려 줘.

03

MCP 시연 선택

AI에 새 도구를 꽂아 주면, 할 수 있는 일이 확 늘어납니다.

03 · MCP란

MCP는 AI용 USB 포트다.

USB에 마우스·프린터를 꽂듯, MCP로 AI에 '한글 문서 도구', '법령 검색 도구'를 꽂습니다.

📄

kordoc

HWP·HWPX 한글 문서를 읽고, 빈칸을 채우고, 새로 만듭니다.

github.com/chrisryugj/kordoc

⚖️

korean-law

법제처 자료로 법령·조례·판례를 찾아 줍니다. 법제처 Open API 키가 필요합니다.

github.com/chrisryugj/korean-law-mcp

🔌

연결 방법

각 저장소의 설치 안내를 AI에게 그대로 주고 "이거 설치해 줘"라고 하면 대부분 알아서 합니다.

03 · 가정통신문 · 폴더 2

한글 양식, 열어 둔 채로 채운다.

kordoc이 연결돼 있으면 hwpx 양식의 서식을 그대로 두고 내용만 바꿉니다.

시연 프롬프트
'2 MCP 시연 (선택) - 가정통신문' 폴더의 메모를 읽고, '가정통신문 양식.hwpx'로 '디지털 새싹' 캠프 안내 가정통신문을 만들어 줘. 양식 서식은 그대로 두고, 다 되면 결과를 보여 줘.
시연 프롬프트 · 법령
초등학교 현장체험학습을 할 때 학교가 지켜야 할 안전 관련 법령 조항을 찾아서, 교사가 알기 쉽게 세 줄로 정리해 줘. 근거 조문도 같이 알려 줘.

04

웹 작업

AI가 브라우저를 직접 열어 검색하고, 비교하고, 표를 채웁니다.

04 · 학습준비물 · 폴더 3

빈 양식을 AI가 다 채운다.

조건

  • 예산 20만 원 안에서
  • 아이스크림몰을 중심으로 검색
  • 정확히 맞추되, 조금 모자란 건 괜찮음
  • 입력하는 모습을 화면에 띄워서

성공 기준

  • 품목·단가·수량·금액이 다 채워졌다
  • 합계가 20만 원을 넘지 않는다
  • 상품 링크로 가격을 다시 확인할 수 있다
실습 프롬프트
'3 웹 작업 - 학습준비물' 폴더의 '학습준비물 메모.md'를 읽고, 브라우저로 가격을 찾아서 '학습준비물 빈 양식.xlsx'를 채워 줘. 합계가 예산을 넘지 않는지 마지막에 확인해 줘.
주의 · 결제는 AI에게 맡기지 않습니다. 장바구니까지만, 결제 버튼은 사람이 누릅니다.

05

미니 비서 만들기

AI는 대화가 끝나면 잊어버립니다. 그래서 파일에 적어 두고 기억하게 합니다.

05 · 비서의 구조 · 폴더 4

규칙 한 장, 홈 한 장, 카드 몇 장.

4 미니 비서/ ├─ AGENTS.md ← 비서의 규칙 ├─ HOME.md ← 카드 목록·마감 └─ 카드/ ├─ 친목회 결산.md ├─ 학습준비물 구입.md └─ 학부모 상담 주간.md

AGENTS.md

"너는 6학년 담임의 업무 비서다"처럼 역할과 일하는 순서를 적습니다. Codex는 자동으로 읽고, Claude는 CLAUDE.md를 자동으로 읽습니다.

HOME.md

지금 진행 중인 카드와 마감일을 한눈에 보는 표입니다.

카드

일 하나에 파일 하나. 할 일 체크박스와 날짜별 기록이 들어갑니다.

05 · 비서 써 보기

말로 시키면, 파일이 바뀐다.

1단계 · 출근
'4 미니 비서' 폴더의 AGENTS.md를 읽고 그 규칙대로 내 비서가 되어 줘. 오늘 뭐 해?
2단계 · 일 끝냄
학습준비물 품의 올렸어.
3단계 · 새 일
12월 5일까지 겨울방학 생활 안내문 만들어야 해. 할 일로 넣어 줘.

확인: 카드에 체크·기록이 남고, HOME.md 표가 함께 바뀌었나요? 일정 앱(구글 캘린더 등)을 연결하면 일정까지 넣어 줍니다.

06

잘 맡기는 법

AI도 신규 선생님처럼, 설명을 잘 들으면 일을 잘합니다.

06 · 맡기는 요령

대화가 길수록, AI는 흐려진다.

🧭

상황 · 목표 · 기준

무슨 상황인지, 무엇을 원하는지, 어떻게 되면 성공인지 세 가지를 말해 주세요. 메모 파일로 주면 더 좋습니다.

🔍

끝나면 확인시키기

"끝나면 합계를 검산해 줘", "바꾼 내용을 알려 줘"를 붙이면 실수가 크게 줄어듭니다.

🧹

일이 바뀌면 새 대화

한 대화에 여러 일을 쌓으면 앞 내용이 섞입니다. 새 일은 새 세션에서 시작하세요.

👀

마지막은 사람

숫자·날짜·이름은 꼭 직접 봅니다. 결재와 결제는 사람이 합니다.

06 · 헷갈리는 세 가지

규칙, 요령, 도구.
