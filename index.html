개인정보는 빼고

학생 이름·연락처·성적은 넣지 않습니다. 넣은 내용은 AI 회사 서버로 전송됩니다.

앱 사용법 · 화면 구성

화면은 네 부분만 알면 된다.

  1. 왼쪽 목록지난 대화(세션)들. 새 일은 새 세션으로 시작합니다.
  2. 작업 폴더AI가 들어와 일할 폴더. 오늘은 실습 폴더.
  3. 가운데 대화AI가 무엇을 하는지 실시간으로 보여 줍니다.
  4. 아래 입력창여기에 말로 지시합니다. 모델·권한도 여기서 바꿉니다.

앱 사용법 · 폴더 열기

AI에게 폴더 열쇠를 준다.

AI는 내가 고른 폴더 안에서만 일합니다. 실습 폴더를 압축 푼 위치를 기억해 두세요.

ClaudeCode 탭 입력창 위의 폴더 선택 → 압축 푼 실습폴더 선택
Codex새 작업에서 프로젝트(폴더) 열기 → 실습폴더 선택

앱 사용법 · 권한과 승인

파일을 바꾸기 전에, 먼저 묻는다.

  1. 승인 창이 뜨면 읽는다어떤 파일을, 어떤 명령으로 바꾸려는지 적혀 있습니다.
  2. 허용 또는 거부모르겠으면 거부하고 "왜 필요해?"라고 물어보세요.
  3. 익숙해지면 모드 조절매번 묻기 → 편집은 자동 허용 → 계획 먼저 보기 등
Claude입력창 아래 권한 모드에서 선택
Codex입력창 아래 승인 모드에서 선택 (읽기 전용 · 자동 · 전체 권한)

앱 사용법 · 모델 고르기

어려운 일엔 똑똑한 모델, 쉬운 일엔 빠른 모델.

🧠 가장 똑똑한 모델

엑셀 결산, 문서 작성처럼 틀리면 안 되는 일. 대신 사용량이 빨리 줄어듭니다.

⚡ 빠른 모델

파일 이름 바꾸기, 간단한 정리처럼 단순한 일.

두 앱 모두 입력창 근처의 모델 이름을 눌러 바꿉니다. 남은 사용량도 설정에서 확인할 수 있어요.

앱 사용법 · 지시하고 확인하기

말로 시키고, 눈으로 확인한다.

  1. 말로 지시"메모 읽고 엑셀 채워 줘"처럼 평소 말투로 충분합니다.
  2. 할 일 목록 보기AI가 세운 계획과 지금 하는 단계가 표시됩니다.
  3. 바뀐 파일 확인어떤 파일이 어떻게 바뀌었는지 직접 열어 봅니다.
  4. 다시 시키기마음에 안 들면 "합계가 틀렸어, 다시 봐 줘"라고 이어서 말합니다.

02 · 친목회 회계 · 폴더 1

결산했는데, 빠뜨린 게 있다.

상황

  • 3~4월 거래 4건은 엑셀에 정리해 둠
  • 10/6 회비 50만 원 입금 → 안 적음
  • 10/15 떡값 10만 원 지출 → 안 적음
  • 회비 입금자명은 '충북보은초'

성공 기준

  • 두 거래가 날짜순으로 들어갔다
  • 맨 위 수입·지출·잔액이 다시 계산됐다
  • 잔액이 이전보다 40만 원 늘었다
  • 기존 서식이 깨지지 않았다
실습 프롬프트
'1 로컬 작업 - 친목회 회계' 폴더의 '친목회 상황 메모.md'를 읽고, 빠진 거래를 '보은초 친목회 회계.xlsx'에 넣어 줘. 맨 위 결산(수입·지출·잔액)도 다시 맞추고, 끝나면 무엇을 바꿨는지 알려 줘.

04 · 학습준비물 · 폴더 3

빈 양식을 AI가 다 채운다.

조건

  • 예산 20만 원 안에서
  • 아이스크림몰을 중심으로 검색
  • 정확히 맞추되, 조금 모자란 건 괜찮음

  • 품목·단가·수량·금액이 다 채워졌다
  • 합계가 20만 원을 넘지 않는다
  • 상품 링크로 가격을 다시 확인할 수 있다
실습 프롬프트

CodexCodex의 브라우저 기능을 켜 두면 같은 프롬프트로 검색합니다.
